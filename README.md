# go-tree

`tree` command implementation in **Golang**.

## Motivation

This repository is for learning purposes only.

## Usage

```bash
# Display tree
go-tree

# Only list directories
go-tree -d

# Limit depth
go-tree -l 2

# Output results as JSON (supports -json, -J, or -j)
go-tree -json
go-tree -J
```
